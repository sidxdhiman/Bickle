## ⚡ Highlights

- **🪟 macOS-style Dock** — floating glass bar with hover magnification, position (bottom/left/right), size, opacity, labels, and accent tint that matches your wallpaper
- **🎨 Smart Backgrounds** — classy gradient-mesh presets or upload your own photo; the app samples the dominant color and retints the entire UI (icons, buttons, dock) automatically
- **👥 Guest Sessions** — hand someone a scoped, expiring session with access to only the pages you grant. Hand it back, it's gone.
- **🌙 Themes** — dark / light, three font families, all persisted locally
- **📴 Fully local** — your data lives in a single SQLite file inside the app's data folder. Nothing phones home. No database server, no account required.

## 🚀 Quick Start

### Users — just install it

Download an installer from the [Releases page](https://github.com/sidxdhiman/Bickle/releases):

- **Linux:** `Bickle-1.0.0.AppImage` (chmod +x, run) or `bickle_1.0.0_amd64.deb` (dpkg -i)
- **Windows:** `Bickle Setup 1.0.0.exe` (NSIS installer)

First launch creates the data folder (`~/.config/Bickle/` on Linux, `%APPDATA%\Bickle` on Windows). No MongoDB, no Node, no terminal.

### Developers

```bash
git clone https://github.com/sidxdhiman/Bickle.git
cd Bickle

# Web dev mode — two terminals:
npm run backend          # API on http://127.0.0.1:9000 (SQLite, auto-seeded)
npm run frontend         # Vite on http://localhost:5173/bickle/

# Desktop app (serves frontend/dist from the embedded server):
npm install              # root: electron + electron-builder
npm run build:frontend   # once, or after frontend changes
npm start                # electron .
```

Gates and packaging (all run from the repo root):

```bash
npm run db:check   # SQLite schema/round-trip checks
npm run smoke      # end-to-end API smoke test
npm test           # isolation / modules / profiles suites
npm run dist       # build AppImage + deb + Windows NSIS installers
```

Backend config is env-driven: `PORT` (9000), `SQLITE_PATH`, `UPLOAD_DIR`, `SERVE_DIST`, `JWT_SECRET`, `SEED_PASSWORD` (login profiles `me` / `d`). `.env` is optional.

## 🗂️ Layout

```
Bickle/
├── backend/
│   ├── config/        # profiles, page-access maps, upload root
│   ├── controllers/   # tasks, notes, calendar, money, habits…
│   ├── db/            # SQLite schema, helpers, round-trip checks
│   ├── middleware/    # auth (JWT + guest scopes)
│   ├── routes/        # /api/* endpoints
│   ├── smoke.js       # end-to-end smoke gate
│   └── server.js
├── electron/
│   └── main.js        # desktop shell — embeds the server, opens the window
├── build/             # app icons (png/ico) for installers
└── frontend/
    ├── src/
    │   ├── components/   # Dock, TopNav, modals, BackgroundLayer…
    │   ├── config/       # page registry
    │   ├── context/      # AccessContext (guest sessions)
    │   ├── hooks/        # useDockSettings, useNavMode, useBackground
    │   ├── layouts/      # MainLayout
    │   ├── pages/        # one file per module
    │   └── utils/        # theme, color extraction, presets
    └── index.html
```
